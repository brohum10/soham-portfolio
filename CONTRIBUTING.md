# Contributing to the Portfolio

This repository is Soham Jindal's public engineering portfolio. Changes should improve clarity, accessibility, accuracy, or maintainability without turning the site into a generic template.

## Local checks

```bash
npm ci
npm run check
```

Use `npm run dev` for local review and `npm run preview` to inspect the production build.

## Expectations

- Keep experience and project claims consistent with the résumé and linked repositories.
- Attach a reproducible source to every performance number.
- Preserve keyboard navigation, visible focus, semantic structure, mobile layout, and reduced-motion support.
- Avoid adding analytics, trackers, or heavy dependencies without a clear benefit.
- Update tests when navigation or project discovery behavior changes.

Pull requests should include the pages or components changed, checks run, and screenshots for material visual changes.
